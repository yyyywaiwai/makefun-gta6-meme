# GTA 6 meme — make.fun bounty entry

Entry for make.fun's [“Post a GTA 6 meme on X”](https://make.fun/bounty/gta6-meme-x-01) bounty.

The meme: thirteen years of waiting for GTA VI turned the player into a
skeleton in front of a “DELAYED AGAIN” screen — while the make.fun ghost,
magenta star coin in hand, got paid in thirteen minutes. It was posted on X
and `POST.json` points at that post.

## Run it

    mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts

`main.ts` (Node 22) copies `POST.json` to the output directory, which is all
this program does.
